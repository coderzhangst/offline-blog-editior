> **双击一个 HTML 文件，你就拥有了一个功能完备的所见即所得博客编辑器。**
> 不需要安装、不需要联网、不需要服务器、不需要数据库——写完导出成一个 HTML，随地再打开继续写。

界面布局**风格参考**国内主流技术博客创作中心（熟悉上手零成本），**所有代码均由KIMI生成**，且**所有数据都留在你自己的浏览器里**（IndexedDB，容量数百 MB）。

## 🤔 有什么特点?

| 痛点                             | 本项目的答案                                                 |
| -------------------------------- | ------------------------------------------------------------ |
| 在线编辑器动不动保存失败、丢稿子 | IndexedDB 大容量存储：**每篇文章独立草稿 + 50 个增量历史版本**，撤销/重做逐步回退 |
| 图片要传图床，换设备就裂图       | 图片/视频**全部 base64 内嵌**，导出一个文件就能带走          |
| 代码块没有高亮                   | **33 种语言实时语法高亮**（含 x86 / ARM 汇编），纯离线渲染   |
| 想画流程图/时序图                | 内置 **Mermaid 离线渲染**：流程图、时序图一键出 SVG          |
| 想写数学公式                     | 内置**公式编辑器**：符号面板 + LaTeX + 实时预览，可拖拽缩放  |
| 环境配置地狱                     | **没有构建、没有依赖、没有 node_modules**，浏览器打开就能改  |

## 🚀 三分钟上手

1. 下载 `离线编辑器.html`（整个项目就这一个文件）
2. 双击，用浏览器打开（推荐 Chrome / Edge）
3. 开写 → 点右下角橙色按钮「导出到电脑」
4. 想继续编辑：打开编辑器 →「打开 HTML」→ 选文章，**完整恢复**

## ✨ 功能一览

### 📝 编辑

- 富文本：加粗（按钮实时显示状态）/ 斜体 / 下划线 / 删除线 / 上下标 / 清除格式
- 段落格式：正文 + 标题一 ~ 标题六（下拉实时打 ✓；六级阶梯字号，H6 不小于正文）
- 字体颜色 / 背景色：共用一个 9×5 色板（右上角 ⓘ 可查看 RGB 排布、一键**导出真·xlsx** 带色块）
- 无序 / 有序列表、左 / 居中 / 右对齐（当前对齐方式带 ✓）
- 块引用、水平线
- **表格**：完整「表格属性」对话框（行列/标题单元格/边框/间距/边距/对齐/标题/摘要）
- **链接**：「插入链接」对话框（URL + 替换文本）
- **公式编辑器**：符号面板 + LaTeX 输入 + 实时预览；插入后单击选中、**右下角拖拽缩放**、双击重新编辑
- **插入代码**：33 种语言下拉，输入时实时语法高亮（One Dark 配色、注释绿色、15px 大字），单击编辑 / 拖动选中两不误，右上角语言角标
- **Mermaid**：`graph`/`flowchart` 流程图（矩形/圆角/菱形/圆柱、边标签、五种方向）、`sequenceDiagram` 时序图，离线渲染为 SVG，双击改源码自动重渲
- 字数统计、标题 5~100 字校验（空标题导出自动命名「无标题 N」）

### 🎨 媒体

- 图片：本地 / URL（可下载转 base64）/ 拖拽 / 粘贴截图，全部 base64 内嵌；选中蓝色描边 + 右下角手柄拖拽缩放、光标自动跟随
- 视频：本地 / URL，base64 内嵌；选中后**右边框直接拖动调整大小**
- 导出时自动把文章里的远程图片**转存为 base64**（联网时）

### 📚 目录

- 左侧目录面板：H1~H6 自动生成、点击跳转、点击标题栏收起为细边条（双向箭头旋转）
- 工具栏「目录」按钮：在光标上方插入文章目录

### 💾 草稿与历史（IndexedDB，容量数百 MB）

- **草稿箱**（工具栏右上角按钮）：所有文章的草稿下拉列表，点击切换、✕ 删除（连带删历史）、底部实时占用统计
- **保存草稿**：Ctrl+S；15 秒自动保存；每篇文章独立存储
- **历史版本**：每篇 50 个版本、**增量存储**（只记变动部分）；毫秒级时间戳、最近一条红底高亮、底部占用统计
- **撤销 / 重做**：在历史版本间逐步回退/前进，历史列表联动裁剪、落点日期自动更新、面板实时刷新
- **打开 HTML**：本编辑器导出的文件**完整恢复**继续编辑；任意网页 / SingleFile 保存的 HTML 也能导入

### 📤 导出

- **导出到电脑**：系统原生保存窗口写 HTML（不支持时退回下载）；可选「正文包含标题」
- 导出前自动转存远程图片；导出正文自动瘦身（剥编辑器内部标记），回导 JSON 保留完整数据
- 导出的文章是独立 HTML：自带排版样式、代码高亮、公式、Mermaid SVG，双击直接阅读

## ⚠️ 已知限制

- 浏览器安全策略**无法获取本地文件完整路径**，本地图片/视频一律 base64 内嵌
- base64 会让含大视频的 HTML 体积增大约 1/3，这是单文件离线化的代价
- 远程图片转存需联网，对方禁止跨域时保留原链接并提示
- 草稿存于浏览器 IndexedDB，清除站点数据会丢失，重要文章请及时导出
